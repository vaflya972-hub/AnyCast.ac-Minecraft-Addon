# Протокол подписи адреса (версия 1)

Край anycast.ac (mcfront) и плагин договариваются через поле «адрес сервера» в пакете Handshake (0x00, состояние HANDSHAKING).

## Когда край добавляет подпись

Только в рукопожатии входа: `next state` 2 (login) или 3 (transfer, 1.20.5+). Пинги списка серверов (`next state` 1) и старый пинг `0xFE` уходят на сервер без изменений.

## Формат поля

```
<имя от клиента> "///" base64url(payload) [<хвост от первого \0>]
```

- `имя от клиента` берётся как есть, до первого `\0`;
- хвост от `\0` (маркеры Forge `\0FML\0`, `\0FML2\0`, `\0FML3\0`) сохраняется в конце;
- base64url без `=` в конце.

Клиент сам такое поле прислать не может: край отбрасывает рукопожатия, где в имени есть `///` или пересылка BungeeCord через `\0`.

## payload

| Смещение | Размер | Поле                                               |
|----------|--------|----------------------------------------------------|
| 0        | 1      | версия, `1`                                        |
| 1        | 1      | флаги: бит 0 = IPv6                                |
| 2        | 4 / 16 | адрес игрока (IPv4 или IPv6)                       |
| 6 / 18   | 2      | порт игрока, big-endian                            |
| 8 / 20   | 4      | время подписи, секунды Unix, big-endian            |
| 12 / 24  | 16     | `HMAC-SHA256(key, "anycast-mc/1" ‖ payload[0:12/24])`, первые 16 байт |

Итого 28 байт для IPv4 (38 символов base64url, вместе с `///` 41 байт) и 40 байт для IPv6.

`key` это 32 случайных байта, у каждого сервера свой. В панели и в `config.yml` он записан base64url (43 символа).

## Проверка в плагине

1. Соединение пришло с адреса из списка anycast.ac (или из `allow`).
2. Версия 1, длина сходится с флагом IPv6.
3. HMAC сходится (сравнение за постоянное время).
4. `|сейчас − время| ≤ signature-max-age-seconds` (по умолчанию 600).
5. Одна подпись пускает один вход: повтор отбрасывается.

После проверки поле адреса возвращается к виду `<имя>[хвост]`, а адрес соединения на сервере меняется на адрес игрока.

## Контрольный пример

```
key       = 00 01 02 … 1f (32 байта подряд)
игрок     = 203.0.113.7:54321
время     = 1762632000
payload   = AQDLAHEH1DFpD6FAaiRW4wYrje8W6qT5AMWjAA
```

Этот же пример проверяют тесты края (Go) и плагина (Java).
